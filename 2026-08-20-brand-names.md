# Five brand names

Coined 7–8 letter names. Tech-oriented, say-once, intended for `.com` / `.tech` / `.io` / `.ai` / `.dev`.

Short dictionary-style names in this space were already taken (`Plyra`, `Merivo`, `Candora`, `Attesta`, `Verora`, `Skillora`, `Hirevox`).

## Ranked for this product

| Rank | Name | Say it | Best at | Watch-out |
|---|---|---|---|---|
| 1 | **Plytara** | PLY-tar-uh | Brand pedigree | Subtle meaning; neighbor **Plytix** (PIM, different word) |
| 2 | **Meritvox** | MEH-rit-vox | Honesty thesis | Neighbor **HireVox** (hirevox.ai), `-vox` class |
| 3 | **Bespokra** | bes-POH-krah | Tailoring thesis | People may type `bespoke`; tiny X `@bespokraft` (woodworker) |
| 4 | **Provevox** | PROOV-vox | Punch / no fiction | Empty GitHub **user** `provevox` (May 2025, 0 repos) |
| 5 | **Provtara** | prov-TAR-uh | Cleanest unused | Slightly less “unicorn” |

Honorable mention, **not** in the five: **Plynexa** (ply-NEX-uh). All five TLDs free, but hobby YouTube `@Plynexa_018` (6 subscribers) already uses the word.

## 1. Plytara

*Ply* = craft of applying. *Tara* = star.

**Tagline:** Your real skills. The right role.

Pick this if you want the name to sound expensive before anyone reads the homepage.

## 2. Meritvox

*Merit* = earned skill. *Vox* = voice. The system only voices what the candidate has done.

**Tagline:** We speak only your merit.

Pick this if the never-fabricate rule is the thing the market should remember.

## 3. Bespokra

Bespoke in a tech spelling: cut to the wearer from cloth that already exists. Resume in first, then tailor — never a generated persona.

**Tagline:** Tailored to the job. Cut from cloth you already own.

Own `bespokra` and 301 obvious misspellings later (`bespoke…`).

## 4. Provevox

Shorter sibling of Meritvox. “Prove it” is how engineers already talk.

**Tagline:** Proven skills. No fiction.

GitHub **user** `provevox` is an empty squat, not a product. You cannot create org `provevox` until that user is gone. Domains were still registry-free.

## 5. Provtara

*Prove* + *tara*. Same silhouette as Plytara, with proof baked in. No GitHub/X/Companies House/OpenCorporates hit.

**Tagline:** Prove the fit. Don’t fake it.

## Positioning this name must carry

- IT jobs only
- Resume-first
- Particularize to the chosen job
- Matching cover letter
- **Never manufacture skills to close a gap**
